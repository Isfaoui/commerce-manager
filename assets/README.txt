Put your app icon here as icon.ico (256x256 recommended) if you want a
custom icon instead of the default one.

Free .ico converters (from a .png) are easy to find online if you only
have a logo image.

Once you have assets/icon.ico:
- In CommerceManager.spec, uncomment the icon= line
- In CommerceManager.iss, uncomment the SetupIconFile= line
